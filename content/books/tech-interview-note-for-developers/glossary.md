가나다순. 정의는 그 용어가 처음 나온 장의 것을 쓰고, 뒤에 그 장으로의 링크를 붙인다.

그라운드 룰
: 팀 구성원이 상호 협의해 정한, 일하는 방식의 기본 규칙.
  — [8장 기술 면접 이후 만나게 될 난관](/books/tech-interview-note-for-developers/after-tech-interview/)

기술 부채 (technical debt)
: 쓰지 않는 코드나 히스토리를 파악할 수 없는 레거시처럼 누적되어 가는 유지보수 비용.
  — [8장 기술 면접 이후 만나게 될 난관](/books/tech-interview-note-for-developers/after-tech-interview/)

디브리프 (debrief)
: 인터뷰 종료 후 면접관들이 모여 지원자의 강점과 약점을 공유하고 최종 채용 여부를 결정하는 회의.
  — [2장 지원하려는 회사와 목표 정하기](/books/tech-interview-note-for-developers/finding-companies/)

루프 인터뷰 (loop interview)
: 전문 분야가 다른 여러 면접관이 여러 단계로 진행하는 1대1 인터뷰.
  — [2장 지원하려는 회사와 목표 정하기](/books/tech-interview-note-for-developers/finding-companies/)

매몰비용 효과
: 이미 지불한 비용 때문에 중도 포기를 꺼리게 되는 심리. 스터디 회비로 참여율을 높이는 장치로 쓴다.
  — [4장 시선을 사로잡는 커리어, 경력기술서](/books/tech-interview-note-for-developers/career-portfolio/)

바 레이저 (bar raiser)
: 채용 부서와 이해관계가 없는 다른 부서 면접관이 참여해 리더십과 기술을 평가하는 최종 단계.
  — [2장 지원하려는 회사와 목표 정하기](/books/tech-interview-note-for-developers/finding-companies/)

비기능적 요구사항 (NFR, Non-Functional Requirements)
: 시스템이 무엇을 해야 하는지가 아니라 어떻게 수행해야 하는지를 정의하는 제약. 성능, 보안, 유지보수성, 확장성, 가용성이 해당하며 측정 가능해야 한다.
  — [7장 기술 면접 대비하기](/books/tech-interview-note-for-developers/tech-interview/)

비즈니스 임팩트
: 개인 업무에서 수치로 증명할 수 있는 성취. 상위 회사가 경력에서 확인하려는 대상이다.
  — [2장 지원하려는 회사와 목표 정하기](/books/tech-interview-note-for-developers/finding-companies/)

빅오 표기법 (Big-O notation)
: 시간 복잡도를 나타내는 표기. O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) 순으로 커진다.
  — [6장 코딩 테스트 준비 전략](/books/tech-interview-note-for-developers/coding-test/)

사이닝 보너스 (signing bonus)
: 새로 합류하는 직원에게 지급하는 일회성 인센티브.
  — [8장 기술 면접 이후 만나게 될 난관](/books/tech-interview-note-for-developers/after-tech-interview/)

성능 테스트
: 응답 시간·안정성·처리량을 확인하는 절차. 병목 지점 식별과 장애 감지 임계치 설정이 목적이다.
  — [7장 기술 면접 대비하기](/books/tech-interview-note-for-developers/tech-interview/)

소프트 스킬 (soft skill)
: 문제 인식과 접근 방식, 의사소통, 협업, 태도, 메타인지처럼 함께 일하는 능력에 관한 역량. 면접 자리에서만 확인된다.
  — [5장 프로그래머의 역량](/books/tech-interview-note-for-developers/programmer-competency/)

손실 회피 (loss aversion)
: 이익을 얻는 것보다 손실의 고통을 더 크게 느껴 회피하려는 경향.
  — [4장 시선을 사로잡는 커리어, 경력기술서](/books/tech-interview-note-for-developers/career-portfolio/)

스크리닝 (screening)
: 후보자의 자격·경험·기술을 검토해 적합 여부를 판단하는 초기 단계.
  — [2장 지원하려는 회사와 목표 정하기](/books/tech-interview-note-for-developers/finding-companies/)

스택 (stack)
: 후입선출(LIFO) 구조. 마지막에 삽입된 데이터가 먼저 제거된다.
  — [6장 코딩 테스트 준비 전략](/books/tech-interview-note-for-developers/coding-test/)

슬로우 쿼리 (slow query)
: 실행 시간이 긴 쿼리. 애플리케이션 성능 저하의 대표 원인이다.
  — [7장 기술 면접 대비하기](/books/tech-interview-note-for-developers/tech-interview/)

시간 복잡도 (time complexity)
: 입력 크기가 커질 때 실행 시간이 늘어나는 정도.
  — [6장 코딩 테스트 준비 전략](/books/tech-interview-note-for-developers/coding-test/)

역량
: 경험, 기술 지식, 커뮤니케이션 능력의 총합으로 일을 처리해내는 능력.
  — [8장 기술 면접 이후 만나게 될 난관](/books/tech-interview-note-for-developers/after-tech-interview/)

옆그레이드
: 지금과 비슷한 수준의 회사로 옮기는 이직. 특별한 사유가 없다면 발전 가능성이 없다는 신호로 읽힌다.
  — [2장 지원하려는 회사와 목표 정하기](/books/tech-interview-note-for-developers/finding-companies/)

의사코드 (pseudocode)
: 실제 문법 대신 논리 흐름만 서술한 코드. 시간이 부족할 때 풀이 방향을 전달하는 수단으로 쓴다.
  — [6장 코딩 테스트 준비 전략](/books/tech-interview-note-for-developers/coding-test/)

잔디 관리
: 깃 커밋 기록이 날짜별 초록색 매트릭스로 표시되는 것. 꾸준한 활동 여부를 판단하는 수단으로 쓰인다.
  — [4장 시선을 사로잡는 커리어, 경력기술서](/books/tech-interview-note-for-developers/career-portfolio/)

컬처 핏 (culture fit)
: 조직 고유의 문화와 룰에 적합한 사람인지 판단하는 면접.
  — [2장 지원하려는 회사와 목표 정하기](/books/tech-interview-note-for-developers/finding-companies/)

큐 (queue)
: 선입선출(FIFO) 구조. 먼저 삽입된 데이터가 먼저 제거된다.
  — [6장 코딩 테스트 준비 전략](/books/tech-interview-note-for-developers/coding-test/)

테이블 파티셔닝 (table partitioning)
: 큰 테이블을 연도·월 같은 기준으로 나눠 저장하는 구조 개선. 데이터가 선형 증가할 때 생기는 조회 지연의 근본 해법이다.
  — [7장 기술 면접 대비하기](/books/tech-interview-note-for-developers/tech-interview/)

하드 스킬 (hard skill)
: 전공 지식, 프로그래밍 언어, CS 지식처럼 측정 가능한 기술 역량.
  — [5장 프로그래머의 역량](/books/tech-interview-note-for-developers/programmer-competency/)

행동 양식 기반 면접 (behavioral interview)
: 과거의 행동이 미래 행동을 예측하는 가장 좋은 지표라는 가정에 기반한 면접 방식.
  — [8장 기술 면접 이후 만나게 될 난관](/books/tech-interview-note-for-developers/after-tech-interview/)

환각 (hallucination)
: AI 도구가 거짓 정보를 사실인 것처럼 생성하는 현상. 검증과 수정은 사용자 몫이다.
  — [3장 취업과 이직을 위한 첫걸음, 이력서와 자기소개서](/books/tech-interview-note-for-developers/resume-and-cover-letter/)

QPS (queries per second)
: 초당 쿼리 수. 서버 처리량을 나타내는 지표다.
  — [7장 기술 면접 대비하기](/books/tech-interview-note-for-developers/tech-interview/)

STAR 기법
: 상황(Situation)·과제(Task)·행동(Action)·결과(Result) 네 단계로 나눠 설명하는 답변 구조.
  — [8장 기술 면접 이후 만나게 될 난관](/books/tech-interview-note-for-developers/after-tech-interview/)

TIL (Today I Learned)
: 오늘 배운 것을 매일 정리해 커밋으로 남기는 기록 방식.
  — [4장 시선을 사로잡는 커리어, 경력기술서](/books/tech-interview-note-for-developers/career-portfolio/)
