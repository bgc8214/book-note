## 핵심 아이디어

테스트와 좋은 설계가 상호보완적인 이유는 둘이 추구하는 목표에 교집합이 있기 때문이다.
좋은 설계는 시스템이 모듈로 분해되어 각 모듈이 독립적으로 개발될 수 있기를 원하고,
테스트도 같은 것을 원한다.

## 요점

- 테스트가 추구하는 가치와 좋은 설계가 추구하는 가치에는 교집합이 있다. 둘 다 모듈의 독립성을 원한다.
- 좋은 설계를 따르면 테스트가 쉬워지고, 테스트를 작성하면 설계가 나아진다.
- 무엇을 테스트해야 하는지는 Right-BICEP이 알려준다.
- 테스트 환경에서 데이터의 경계 조건에 무엇이 있는지는 CORRECT가 알려준다.

## 실천 아이템

- [ ] 테스트 대상을 고를 때 Right-BICEP을, 경계 조건을 짤 때 CORRECT를 체크리스트로 쓴다.
- [ ] 테스트가 어려운 모듈을 설계 개선 후보 목록에 올린다.

## 용어

Right-BICEP
: 무엇을 테스트해야 하는지 알려주는 원칙. 결과가 올바른지에서 시작한다.

CORRECT
: 테스트 환경에서 데이터의 경계 조건에 어떤 것이 있는지 알려주는 원칙.
