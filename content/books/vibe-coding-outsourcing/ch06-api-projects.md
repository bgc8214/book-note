## 핵심 아이디어

단가가 오르는 구간은 API 연동이다. 외부 서비스에서 데이터를 가져와 가공하는 일이고,
그래서 API 의 구조를 이해하는 것이 이 구간의 문턱이 된다.

## 요점

- API 연동은 매크로보다 단가가 높은 구간이다.
- API 의 구조를 이해하면 연결 자체는 어렵지 않다.
- 쇼핑몰 상품 이름 정리, 정보 추출, 거래명세서 데이터 추출 같은 것이 전형적인 의뢰다.
- 데이터를 가져오는 것보다 가공 규칙을 정확히 합의하는 것이 일의 중심이다.

## 실천 아이템

- [ ] API 연동 의뢰를 받으면 데이터 가공 규칙을 문서로 먼저 합의한다.
- [ ] 외부 API 의 사용 제한과 요금 정책을 견적 전에 확인한다.
